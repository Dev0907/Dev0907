## Startup

### [LekhAI: AI Academic Document Platform](https://www.lekhai.live/)
**Founder** | [lekhai.live](https://www.lekhai.live/) | [Project page on portfolio](https://devparikh.vercel.app/startup)

> Shuruaat se manzil takk: an AI co-pilot for academic documents. LekhAI turns a short form, or a conversation with a voice agent, into submission-ready documents. Each document type has its own specialised engine rather than a generic chatbot wrapper. Exports are DOCX, PDF or print-ready.

| Category | Product | Description |
|----------|---------|-------------|
| Academic documents | SOP Architect | Narrative mapping, university tone-match and dynamic revision modes for Statements of Purpose |
| | Resume Architect | Research-first, impact-indexed, ATS-friendly academic CVs with publication formatting |
| | LOR Architect | Professor-persona Letters of Recommendation with project depth and authentic voice |
| | SRS Architect | IEEE 830-1998 specifications with functional requirement trees and sequential FR-IDs |
| | Internship Report | Nine-chapter university-grade reports with feasibility study, test suite and diagram descriptions |
| | SGP Report | Eight-chapter student group project reports covering architecture and implementation |
| AI tools | AI Humanizer | Restructures sentence rhythm and complexity of AI text while keeping tone and intent intact |
| | AI Detector | Sentence-by-sentence AI-probability heatmaps with multi-model detection and university-compliance checks |
| | LORA Editor | Upload PDF, DOCX or ZIP and edit by chatting or by voice |
| | Aira Voice Agent | Speak your thoughts; Aira extracts the fields and structures them into any document type |

#### Impact

| Metric | Result |
|--------|--------|
| First-pass approval | 100%. 20 students from my own batch used LekhAI for final-year internship reports, and every report was approved by the university on first submission |
| Time saved | 40+ hours per student on average |

## Research Publications

Author profile: [Springer Nature Link](https://link.springer.com/researchers/16965673SN) | ORCID: [0009-0006-1391-2334](https://orcid.org/0009-0006-1391-2334)

### [Comprehensive Analysis of Bilingual Text Extraction: OCR Techniques for Gujarati and English](https://link.springer.com/chapter/10.1007/978-981-96-4139-0_26)

**Dev Parikh**, Nikita Bhatt, Dhaval Bhoi

> *Springer LNNS Vol. 1323, pp. 307-316, ICTCS 2024*
> First Online: 14 August 2025 | DOI: [10.1007/978-981-96-4139-0_26](https://doi.org/10.1007/978-981-96-4139-0_26)

In-depth analysis of OCR techniques for extracting and distinguishing Gujarati and English text from bilingual documents. Proposes advanced preprocessing, text segmentation and language identification, and addresses the complex structure, diacritical marks and conjunct letters of Gujarati script. Reports extraction accuracy of 90.75% for English and 91.16% for Gujarati.

### [Natural Language Processing in Email Spam Filtering: A Comparative Study](https://link.springer.com/chapter/10.1007/978-981-96-4142-0_19)

Jay Parmar, **Dev Parikh**, Amit Thakkar, Dhaval Bhoi

> *Springer LNNS Vol. 1324, pp. 225-235, ICTCS 2024*
> First Online: 01 October 2025 | DOI: [10.1007/978-981-96-4142-0_19](https://doi.org/10.1007/978-981-96-4142-0_19)

Comparative study applying NLP techniques to email spam classification. Benchmarks FastText against Bag-of-Words with a Random Forest classifier, using tokenization, stopword removal and stemming for preprocessing, and shows improved resilience and scalability of spam filtering systems.
